自定义规则 ​

自定义规则用来处理分类之外的例外情况，分为两层：日常使用的快捷规则，以及默认折叠的高级规则。

快捷规则 ​

每一行包含一个动作、一种匹配方式和若干个值：

选项可选值
动作直连（DIRECT）、拒绝（REJECT）
匹配方式域名、域名后缀、IP 段
匹配方式含义Clashsing-box
域名完整域名精确匹配，不含子域名DOMAINdomain
域名后缀该域名及其所有子域名DOMAIN-SUFFIXdomain_suffix
IP 段CIDR 网段IP-CIDRip_cidr

例如一行"直连 + 域名后缀"，填入 example.com 和 example.org，生成的 Clash 规则为：

yaml
- DOMAIN-SUFFIX,example.com,DIRECT
- DOMAIN-SUFFIX,example.org,DIRECT

快捷规则直接指向内置的 DIRECT / REJECT，不会新建策略组。

输入方式 ​

  • 多个值可以用逗号、中文逗号、空格或回车分隔，粘贴多行文本会自动拆分。
  • 输入框为空时按退格键，删除最后一个值。

自动规范化 ​

输入结果
https://Foo.com/path?a=1foo.com（只保留主机名并转为小写）
*.example.com（域名后缀）example.com
中文域名转换为 punycode（xn--…）
1.2.3.4（IP 段）1.2.3.4/32
2001:db8::1（IP 段）2001:db8::1/128

格式校验 ​

格式不正确的值会标红，行下方提示"N 个值格式不正确，已忽略"，这些值不会写入订阅。这样可以避免一个非法的 IP 段让整份 sing-box 配置加载失败。纯数字的顶级域（例如把 IP 填进了域名）也视为不合法。

高级规则 ​

展开"高级规则"后，每条规则是一张完整的表单：

字段说明
出站填新名称时，会新建同名策略组（成员包含节点选择、DIRECT、REJECT、自动选择和所有节点）；填 DIRECT / REJECT 时直接指向内置出站，不建组
Geo-Site域名分类名，例如 google、category-ai-!cn
Geo-IPIP 分类名，例如 private、cn、telegram
域名 / 域名后缀 / 域名关键词对应 DOMAIN / DOMAIN-SUFFIX / DOMAIN-KEYWORD
IP CIDRIP 段
协议仅 sing-box 生效，并且与同一条规则的其他条件是"并且"关系，建议单独成条

高级规则会实时检查：

  • 出站名称重复，或与已有策略组同名（会导致客户端加载失败）；
  • Geo-Site 名称是否真实存在。名称不存在时标签标红：sing-box 会因为下载规则集失败而无法加载整份配置。
  • 卡片底部显示这条规则会生成多少条 Clash 规则、指向哪里。

顺序与置顶 ​

  • 生成时先输出快捷规则，再输出高级规则，各自保持界面上的顺序。
  • "置顶"开关默认打开：自定义规则排在所有分类规则之前，优先匹配。关闭后排在分类规则之后、🐟 漏网之鱼 之前。
