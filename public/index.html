规则分类

拖动左侧手柄调整顺序，靠前的分类先匹配，序号即当前优先级。卡片上的数字是该分类的域名数；大分类排在它包含的小分类前面时，会在上方提示。标记「直连」「拦截」的分组默认直连 / 拦截。

03

自定义规则

对指定的域名、域名后缀或 IP 段直连 / 拒绝。多个值可用逗号、空格或回车分隔；粘贴网址会自动提取域名，单个 IP 自动补全为 IP 段。

高级规则 自定义出站、Geo-Site / Geo-IP、关键词、协议

出站填新名称会新建同名策略组，填 DIRECT / REJECT 时直接直连 / 拒绝。高级规则排在上方快捷规则之后。
