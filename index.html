主题

Sublink Worker一个 Worker，管好所有订阅

把节点链接与机场订阅转换为 Clash、sing-box、Xray 配置，部署在你自己的 Cloudflare Workers 上

快速开始
GitHub

多种输入与输出

支持 ss、vmess、vless、trojan、hysteria2、tuic 节点链接和 http(s) 订阅地址，可混合填写；输出 Clash、sing-box 配置与 Xray 节点列表。

18 个规则分类

三档预设或自由勾选，拖动调整匹配优先级；在线统计每个分类的域名数，排序冲突给出提示并可一键修正。

简单的自定义规则

一行选择直连或拒绝，填入域名、域名后缀或 IP 段即可；需要自定义出站、Geo-Site 等时再展开高级规则。

实时预览与固定短链

修改时即可查看生成的配置文件；用固定的短链路径覆盖更新，客户端的订阅地址无需更换。
